# 마무리 (대상: $ARGUMENTS)

이 세션의 작업 단위를 끝내고, 다음 세션이 이어받을 수 있게 기록을 정리한다.
이 세션을 시작할 때 부른 역할 명령(`/plan` 등)의 **"끝낼 때"** 규칙을 따른다. 역할 명령 없이 시작한 세션이면 어떤 상태 전이로 끝낼지 사용자에게 먼저 묻는다.

## 순서
1. `date`로 현재 시각(KST)을 확인한다.
2. 이 세션에서 **실제로 한 일만** 정리한다. 하지 않은 것과 확인하지 못한 것은 그렇게 쓴다. (예: DoD를 실행하지 않았으면 "미실행")
3. 활성 spec의 `진행 기록`에 핸드오프를 추가한다. 형식은 `docs/specs/00-template.md`.
4. 작업 중 모은 ADR·TS·TIL 후보가 있으면 spec의 '기록 후보'에 정리한다 (`AGENTS.md` §8).
5. `SPEC.md`의 해당 행을 고친다: 상태 · 현재 단계 담당 · 마지막 갱신 · 다음 액션. 역할 명령의 '끝낼 때' 규칙대로 바꾼다. **`Approved`와 `Done`은 바꾸지 않고 제안만 한다.**
6. 바뀐 내용을 사용자에게 요약해서 보여주고, **다음에 열 세션 명령을 알려준다.** (예: "다음은 `/verify 03`")
7. 커밋·push는 하지 않는다. 사용자가 지시할 때만 한다.

## 하지 않는 일
- 다음 세션의 일을 미리 하지 않는다.
- 결과를 부풀리지 않는다. 한 일이 적으면 적게 쓴다.
