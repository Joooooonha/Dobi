# ADR — 결정 기록 인덱스

**상태의 유일한 원본이자 한 줄 개요 목록.** 상황·선택지·이유·결과는 `docs/adr/NNNN-*.md`에 있다. 파일에는 상태를 적지 않는다.

## 상태

| 상태 | 뜻 |
|---|---|
| 고민중 | 선택지를 비교하는 중 |
| 채택 | 결정함. 구현·검증 전이거나 진행 중 |
| 검증됨 | 구현·측정 후 파일의 "결과"를 채움. 포트폴리오·면접 자료는 이 상태만 쓴다 |
| 보류 | 지금은 안 함. **재검토 조건 필수** |
| 재검토 | 보류 조건이 충족됐거나 결정에 문제가 발견됨 |
| 폐기 | 하지 않기로 함 (다른 ADR로 대체됐으면 개요에 번호를 적는다) |

## 쓰는 기준 · 방법

- **쓰는 때**: 선택지가 2개 이상이고 되돌리는 비용이 큰 결정. 유형은 기획 / 기술 / 디자인 / 프로세스. 그 외는 spec 안 한 줄로 충분하다.
- 새 ADR: `docs/adr/0000-template.md`를 복사 → 아래 목록에 한 줄 추가. 본문은 고치지 않는다. 상태·결과·변경 이력만 갱신한다.
- 에이전트는 상황·선택지·장단점 후보만 정리한다. **"결정과 이유"는 사용자가 쓴다.**
- 개요는 한 줄. 갱신 시각은 `date`(KST).
